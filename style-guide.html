gracefully.dev — how it’s made

Style guide.

Everything here lives in style.css as custom properties. This page explains what each one is for, so anything new stays part of the same publication.

One

Principlesthe short version

It should read like a page someone wrote, not a screen someone shipped. Serif type, a measured column, paper that isn’t quite flat, rules that wobble the way a hand wobbles.

Warm before formal. Given a choice between the correct move and the friendly one, take the friendly one — softer letterforms, rounder shapes, a little wonk.

Motion is arrival, not decoration. Things settle once. The pen writes once and lifts. Nothing loops.

One accent, used sparingly. Green appears on the full stop, the ink, and hover. Its scarcity is the whole point.

Never trade legibility for effect. Every animation has a reduced-motion path and every interactive element keeps a visible focus ring.

Two

No full capsthe rule that matters most

Small uppercase letterspaced labels are banned. Not discouraged — banned. They read as generic system chrome, the house style of every AI-generated interface and admin dashboard, and they are exactly the opposite of a page someone wrote by hand.

Subtitles, section labels, kickers, eyebrows, button text and meta lines are always sentence case, and almost always set in Caveat, the handwriting face. If a label needs to feel quieter, lower its contrast — never shrink it and shout it.

× no

Section label

Uppercase, letterspaced, tiny, sans-serif. Reads as machine output.

✓ yes

Section label

Sentence case, handwritten, comfortably sized. Reads as a note in the margin.

In practice this means text-transform: uppercase appears nowhere in the stylesheet, and there is no letterspacing token to reach for.

Three

Colourswatches follow the theme you’re in — try the toggle

Tokens are defined on :root for light and overridden under :root[data-theme="dark"]. Never hard-code a hex in a component; add a token instead.

  • paper Page background. Cream, never white.
  • paper-warm Cards and demo panels.
  • paper-sunk Inline code, recessed surfaces.
  • ink Body text. Warm, never pure black.
  • ink-muted Lede, labels, descriptions. Passes contrast.
  • ink-faint Decorative, aria-hidden text only.
  • rule Every wobbly hairline.
  • accent The full stop, the ink, hover.

Contrast. ink on paper clears 14:1 in both themes. ink-muted clears 4.5:1, which is why every label that carries meaning uses it. ink-faint does not clear 4.5:1 and is therefore restricted to decorative text that screen readers skip — the index numbers, and nothing else.

Four

Typethree families, one job each

font-display — Fraunces, soft 100, wonk 1

Gracefully

Wordmarks, headings, app names. The soft and wonk axes are what make it friendly rather than stately — always set both.

font-text — Newsreader

A home for gracefully developed apps, set in italic for emphasis.

Body, lede, descriptions. Italic carries emphasis; bold is not used anywhere on the site.

font-hand — Caveat

Labels, numbers, notes in the margin

Every label and annotation. Caveat has a small x-height, so it never goes below 1.1875rem — handwriting set small is just illegible handwriting.

Scale

Sizes are named by role: --size-display, --size-lede, --size-entry, --size-body, --size-hand, --size-hand-sm. Body copy is capped at --measure (34rem, roughly 70 characters); never let a paragraph run the full --page width.

Five

Texturethree layers, all cheap

The page is never a flat fill. Three things stop it looking printed by a machine, and there is no fourth — resist adding one.

Grain

A fixed feTurbulence layer on body::before at --grain opacity. Pointer-events none, always beneath the content.

Blotch

Three soft radial gradients on body::after in --blotch, so the paper tone drifts across the page.

The wobbly rule

Every hairline on the site is one repeating SVG squiggle, applied as a mask over --rule so it themes correctly. Plain 1px solid borders are not used anywhere. Add the class .rule-wave, or reuse the shared pseudo-element rule.

Six

Motionand the pen

The pen

A fountain pen draws an ink stroke, then lifts off the page. The ink path carries pathLength="1", so the dash animation needs no JavaScript; the nib rides the identical path via CSS offset-path. The d attribute and the path() in CSS must match exactly, or the nib drifts off its own line.

Arrivals

Add .reveal and an --i index to anything that should arrive. --i multiplies by 90ms to stagger the sequence; an IntersectionObserver adds .is-in once and stops watching. Two modifiers: .reveal--display for wordmarks only (slower, with a blur that resolves) and .reveal--rule, which draws an element’s hairline in from the left.

Hover

An index row moves four things at once: the number turns green, the wobbly underline draws under the word, the arrow springs 5px right, and a soft blob of --accent-wash scales in behind everything. Try it:

  1. 01 An example entry → Hover or tab to it, and watch the four things happen.

Easings

--ease for colour and opacity, --ease-expo for arrivals and travel, --ease-bounce for anything that should feel springy, and --ease-pen for the stroke itself — it accelerates out of the first curve and settles into the last, the way a real stroke does.

Reduced motion

prefers-reduced-motion collapses every duration to 0.01ms, forces reveals visible, drops the padding shift and the toggle wobble, and shows the finished ink stroke with no pen. Any new animation must be accounted for in that block.

Seven

Space and shapepick by role, not by size

  • space-2xs

  • space-sm
  • space-md

Corners

Rounded shapes use --radius-blob, which sets four different radii on purpose — nothing on this site should look stamped out by a machine. The theme toggle goes further and uses percentage radii that shift on hover, so it wobbles like a drawn circle. Use --radius-soft only where an uneven shape would read as a mistake.

Eight

Adding thingsthe two jobs you’ll actually do

An app

Edit the apps array near the bottom of index.html. name is title case and short, desc is one line in sentence case, url is absolute. Numbering is generated from array order — don’t write it by hand. Commit, push to main, and Pages redeploys within a minute.

A page

Copy the <head> from 404.html — it carries the font links, the stylesheet, the no-flash theme script and the motion-path check. Wrap content in <main class="page">, reuse .masthead__meta, .wordmark and .lede for the header, add .reveal with sequential --i values, and close with the .colophon footer. Page-specific CSS goes in a <style> block built from existing tokens; if a rule is needed twice, promote it to style.css.

Nine

Accessibilitynon-negotiable

Focus rings are a 2px accent outline at 4px offset — never remove them. Decorative glyphs (arrows, index numbers, the pen) carry aria-hidden="true". The theme toggle’s aria-label describes the action it will perform, not the state it is in. Sections are labelled with aria-labelledby. Colour is never the only signal: hover adds motion and an underline, not just a hue.
